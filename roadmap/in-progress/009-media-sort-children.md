# Media Sort Children

## Problem

The media section has the same **"Sort children..."** entity action as content. Media folders can have their children reordered. This is already covered in the content-focused `003-sort-children.md` report, but worth noting that the same tool should support media sorting too.

## UI Workflow

Same as content sort — see `003-sort-children.md`. Available on media folders via the "..." entity action menu.

## Assessment

The proposed `sort-children` tool in report 003 should support both content and media via a `type` parameter. No separate media-specific tool needed.

## Impact

Covered by report 003.
